# 権限について

## マップの公開範囲

- **URL限定公開**（画面では「公開」）は、共有されたマップの URL からログインせずに開けます。共有フォルダの中にも表示されます。
- **非公開**は、作成者と管理者が開けます。他の人が URL を直接開くと「マップが見つかりません」と表示されます。

## ユーザーごとにできること

表の「自分のマップ」「自分のピン」は、それぞれ自分が作成したものを指します。

| 利用者 | URL限定公開マップ | 非公開マップ |
| --- | --- | --- |
| ログインしていない人 | マップとピンを閲覧できる。 | 閲覧できない。 |
| ログイン済みの一般ユーザー | マップとピンを閲覧できる。ピンを追加でき、自分のマップ・ピンは編集・削除できる。 | 自分のマップを閲覧・編集・削除できる。中のピンを閲覧でき、ピンの追加や自分のピンの編集・削除ができる。他のユーザーのマップとその中のピンは閲覧できない。 |
| 管理者 | 他のユーザーが作成したマップ・ピンも閲覧・編集・削除できる。ピンを追加できる。 | 他のユーザーが作成したマップ・ピンも閲覧・編集・削除できる。ピンを追加できる。 |

- マップの編集では、タイトル・説明・公開範囲を変更できます。管理者がマップやピンを編集しても、元の作成者は保持されます。
- ログイン済みのユーザーは、閲覧できるピンにコメントを投稿し、自分のコメントを編集・削除できます。
- 管理者はヘッダーの「マップ管理」から両方の公開範囲のマップを開けます。マップは詳細画面のメニュー、ピンはピンを開いたパネルから編集・削除できます。
- めもっぷにアップロードしたマップ画像も、マップと同じ閲覧権限で表示されます。

## ユーザー管理

- 管理者はヘッダーの「ユーザー管理」から、登録ユーザーと現在の権限を確認し、管理者権限を付与・解除できます。最後の管理者の権限は解除できません。
- 一覧には Supabase Auth の GitHub 連携情報に保存されたユーザー名と、メールアドレス、ユーザー ID が表示されます。ログイン名の情報がない場合は「GitHub ユーザー名なし」と表示されます。
- フォルダ管理・マップ管理の作成者名や、コメント管理の投稿者名を押すと、ユーザー管理の該当ページが開き、そのユーザーの行を強調します。作成者名には GitHub ユーザー名を使い、取得できない場合はユーザー ID を表示します。
- 一覧の取得と権限の変更は、Supabase 側でも操作した人が管理者か確認します。変更されたユーザーの画面は、ページを再読み込みするか、別のタブから戻ると権限を確認し直します。
- この機能を有効にするには、既存の `is_map_admin()` がある Supabase プロジェクトの SQL Editor で、[ユーザー管理用の SQL](sql/issue-11-admin-users.sql)、[GitHub ユーザー名を追加する SQL](sql/issue-11-admin-github-usernames.sql) の順に、それぞれファイル全体を実行します。ユーザー管理用の SQL を適用済みの場合は、GitHub ユーザー名を追加する SQL を実行します。

## フォルダ管理

- 管理者は「フォルダ管理」から全ユーザーのフォルダを開き、フォルダ画面で名前変更・削除できます。名前変更後も作成者と中身は保持されます。
- 削除前に確認を表示します。中のマップと直下の子フォルダは、削除対象の親フォルダへ移動します。親がない場合はホームへ移動し、各マップ・子フォルダの作成者は保持されます。
- 一般ユーザーは自分のフォルダを名前変更・削除できます。従来の持ち主なしフォルダはログイン済みユーザーが削除できます。ほかのユーザーのフォルダ操作は Supabase 側でも拒否します。
- [フォルダ管理用 SQL](sql/issue-12-admin-folders.sql) の全体を SQL Editor で実行すると、一覧・名前変更・削除・作成者名の取得の関数と実行権限を追加します。実行はユーザーデータの削除や移動を行いません。

## コメント管理

- 管理者はヘッダーの「コメント管理」から、公開・非公開マップのピンに付いたコメントを新しい順に確認できます。マップ名とピン名のリンクを開くと、投稿先のピンと対象コメントが表示されます。
- コメントの投稿者名を選ぶと、ユーザー管理で該当する行が強調されます。メールアドレスはその行で確認できます。
- 管理者はコメント管理の一覧とピンの詳細パネルから、すべてのユーザーのコメントを編集・削除できます。管理用一覧の取得と他のユーザーのコメントの編集・削除は、Supabase 側でも管理者に限定します。編集時は本文だけが変わり、元の投稿者と投稿日時は保持されます。
- 有効にするには、既存の `is_map_admin()` がある Supabase プロジェクトの SQL Editor で、[コメント管理用の SQL](sql/issue-13-admin-comments.sql)、[コメント削除用の SQL](sql/issue-13-admin-delete-comment.sql) の順に、それぞれのファイル全体を実行します。一覧を適用済みの場合は、コメント削除用の SQL を実行します。
- 編集を有効にするには、[コメント編集用の SQL](sql/issue-2-edit-pin-comment.sql) の全体を実行します。
- 投稿者名からユーザー管理の該当ページへ移動できるようにするには、ユーザー管理用の SQL を適用したあと、[投稿者リンク用の SQL](sql/issue-13-admin-comment-author-link.sql) の全体を実行します。
